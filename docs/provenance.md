# Source and license

Track original Rust, browser glue, tooling, documentation and explicitly labelled
synthetic fixtures. Keep official source, assets, credentials and raw captures
outside Git history, issues and PRs. The private readable reference JS is a local
behavioral specification to port idiomatically, never a source to copy into tests.
External comparisons and captures belong outside the checkout.

The index/history guard blocks known bundles, prohibited artifacts and unsafe
vectors. Review authorship separately. Only the original assets/logo.svg and
assets/icon.svg are permitted vector assets.

The logo and icon use an original C-shaped snake. The logo wordmark was typeset
in [Inter Medium](https://github.com/rsms/inter) and converted to paths; Inter is
under the [SIL Open Font License](https://github.com/rsms/inter/blob/master/LICENSE.txt).
The SVGs contain no official artwork, scripts or external resources.

[MIT](../LICENSE) covers authored project files and grants no license to official
client code or artwork. This project is independent of Slither.io.
