# Documentation

The current client covers bounded protocol primitives, atomic scene state,
Canvas2D rendering and an optional local simulator connection.

- [Architecture](architecture.md): modules, supported inputs, and browser scope.
- [Trusted skin provider](skin-provider.md): caller-owned recipes and borrowed-asset readiness.
- [Retained desktop food](food-presentation.md): factories, source ownership and ordered paint passes.
- [Retained prey](prey-presentation.md): independent appearances, motion, capture and borrowed sources.
- [Ordinary antennas](antenna-presentation.md): appearance state, draw cadence, supplied randomness and borrowed bulbs.
- [Browser extension](extension.md): package layout, local installation and integration limits.
- [Verification](verification.md): builds, tests, optional comparisons, and results.
- [Provenance](provenance.md): source/asset policy and external reference identity.
- [Roadmap](roadmap.md): client state, deterministic rendering, and packaging.
- [Optional responsiveness experiments](future/responsiveness.md): saved proposals, not implemented behavior.
- [Releases](releases.md): dormant release configuration and readiness criteria.
- [Contributing](../CONTRIBUTING.md): changes, review, and reporting.

For simulation and server interfaces, use the separate
[slither-sim documentation](https://github.com/NikitaMGrimm/slither-sim/tree/main/docs).
